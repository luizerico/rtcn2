# Agent notes

This repo is a unified Next.js + Express RBAC app.

- Prefer project rules in `.cursor/rules/`
- Prefer project skills in `.cursor/skills/`
- Primary start command: `npm run dev`
- UI: `client/` · API: `api/` · Entry: `server.js`

When unsure, read `README.md` and apply the matching skill (`nextjs-app-router`, `rbac-api-endpoint`, or `verify-app`).
